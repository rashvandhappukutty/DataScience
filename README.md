## 🛠️ Key Concepts & Algorithms Covered

### 1. Python Programming
- **Fundamentals**: Object types, functions, control flow, loops, and list comprehensions.
- **File Handling**: Reading and writing CSV/JSON files, file cursor manipulation, and working with custom collections (`defaultdict`).

### 2. Data Structures & Algorithms (DSA)
- **Linear Data Structures**: Stacks (parentheses validation, postfix evaluation), Queues, and Double-ended Queues (Deques).
- **Non-Linear Data Structures**: Binary Trees (In-Order, Level-Order traversals) and Heaps (Min/Max heaps).
- **Patterns & Techniques**:
  - **Sliding Window**: Maximum window elements, longest substring without repeating characters.
  - **Two Pointers**: Palindrome verification, target sum arrays.
  - **Binary Search**: Fast searching on sorted boundaries.
  - **Recursion & Backtracking**: Generating permutations, Fibonacci sequence, number powers.

### 3. Data Science & Machine Learning
- **Data Preprocessing**: Handling missing values, filtering outliers, and data cleaning.
- **Data Manipulation**: Joining, merging, and concatenating structured datasets.
- **Parsing JSON/CSV**: Loading datasets (e.g., Titanic survivors JSON data) and running analytical queries.

## 🚀 Getting Started

### Prerequisites
Make sure you have Python 3.x installed on your machine. You will also need Jupyter Notebook/Lab to open the `.ipynb` files.

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/rashvandhappukutty/DataScience.git
   cd DataScience
   ```
2. Set up a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```
3. Install required libraries (for Data Science notebooks):
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

### Running Jupyter Notebooks
To run the notebooks inside `DataScience and Machine Learning/`, execute:
```bash
jupyter notebook
```
